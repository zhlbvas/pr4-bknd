# ПР4 - Веб приложение
## Описание проекта
Веб-приложение для работы с данными о местах Астаны. Сервер получает и обрабатывает данные, а на странице они отображаются в виде карточек.

Проект выполнен с использованием HTML, CSS, JavaScript, Node.js, Express.js, JSON.

Запустить можно скачав файлы и ввести в терминал: " npm start ".
